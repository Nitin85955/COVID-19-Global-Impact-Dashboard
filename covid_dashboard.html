Interpretation

The dashboard is descriptive. Confirmed cases and deaths are affected by testing, reporting rules and data availability. Vaccination coverage is not interpreted as a stand-alone causal explanation for mortality differences. For the full reproducible pipeline, run the accompanying Jupyter notebook.
